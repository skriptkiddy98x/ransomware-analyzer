# Disclaimer

`ransomware-analyzer` is a **defensive** malware-analysis tool intended for
**authorized security research, education, and incident response**.

- It observes and reports on samples you provide. It does **not** create, spread,
  weaponize, or decrypt ransomware.
- Detonating real malware is inherently risky. Do it **only** inside an isolated
  virtual machine you control (see `docs/LAB_SETUP.md`). The authors accept no
  liability for any damage resulting from misuse.
- Only analyze systems and samples you are **legally authorized** to handle.
- Family attribution and verdicts are heuristic and may be wrong; treat them as
  triage hints, not definitive classification.

By using this software you agree to use it lawfully and ethically.
